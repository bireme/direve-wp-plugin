# Open Sans (self-hosted)

These unmodified WOFF files are Open Sans version 1.10, designed by Steve
Matteson. They are the same files previously referenced by `template/css/style.css`
(Google Fonts Open Sans v6), downloaded using HTTPS. No conversion or subsetting
was performed. Browser requests now use paths relative to the stylesheet and do
not require a Google font service. Existing `local()` fallbacks are preserved.
